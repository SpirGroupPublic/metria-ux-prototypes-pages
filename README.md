# UX Prototypes

Static site hosting Metria UX prototype pages, published via GitHub Pages.

## What

This repository serves as the publishing platform for UX prototypes. Prototype pages are committed here and served as a static GitHub Pages site. The repository is mirrored to the SpirGroupPublic organisation on every push to `main`.

## Setup

No build step required — the site is plain HTML. Clone the repository and open `index.html` in a browser.

## Usage

Add prototype pages as HTML files and link to them from `index.html`. Push to `main` to publish.
