# Contributing

## Branching model

Create a feature branch from `main`, make your changes, and open a pull request. Branch names should be short and descriptive, e.g. `add-login-prototype`.

## Pull request process

- At least one approving review is required before merging
- Stale approvals are dismissed when new commits are pushed
- Merge directly to `main` once approved — no release branches

## Local setup

No build step required. Open `index.html` in a browser to preview the site locally.
